# PROJECT

Pharma Adherence project for CDD209. Can model data from a pharma adherence dataset.

## Features

- data cleaning
- linear regression
- logistic regression
- patient summary profile
- visualize patient adherence data

## Installation

### Clone the repository

```
git clone [https://github.com/theosyonactual/cdd209-final-template]
```

### Create a virtual environment

```
conda create --name [myenv]
conda activate [myenv]
```

### Install the package

```
cd cdd209-final-template
pip install .
```

## Usage

Use to model data from the given dataset.

## Testing

After installation, in repo folder type:
```
pytest
```
